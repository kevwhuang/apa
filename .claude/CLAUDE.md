# Austin Producer Alliance

Community site for the Austin Producer Alliance, a collective of music producers in Austin, Texas. Features a waveform timeline hero, producer roster with synthesized track players, event calendar spanning Assembly, Hangout, and Bash programs, track feedback and submission dropzones, a Web Audio plugin rack, mock storefront with cart and checkout, resources library, prods rewards system, admin console, member chat, an AI assistant demo, and a site-wide light and dark theme. Built with Astro, React, TypeScript, Tailwind CSS, and GSAP. Deployed on Netlify.
