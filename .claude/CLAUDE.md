# Austin Producer Alliance

Community site for the Austin Producer Alliance, a collective of music producers in Austin, Texas. Features a waveform timeline hero, producer roster with synthesized track players, event calendar spanning Assembly, Hangout, and Producer Bash programs, track feedback and submission dropzones, a Web Audio plugin sandbox, mock storefront with cart and checkout, resources library, prods rewards system, admin console, and member chat. Built with Astro, React, TypeScript, Tailwind CSS, and GSAP. Deployed on Netlify.
