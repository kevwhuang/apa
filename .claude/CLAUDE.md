# Austin Producer Alliance

Community site for the Austin Producer Alliance, a collective of music producers in Austin, Texas. Features a waveform timeline hero, member directory with synthesized track players, photo gallery with a fullscreen viewer, event calendar spanning Assembly, Hangout, and Bash programs, track feedback and submission dropzones, a Web Audio plugin rack, mock storefront with variation-aware cart, discount codes, and checkout, resources library with timed unlocks, Prods rewards, partners page, read-only content API, guided site tour, admin console, site-wide light and dark theme, and floating player, member chat, and AI assistant docks. Accounts are a client-side mock at /signin, with portrait uploads across onboarding and settings, signed-in redirects, and localStorage-only persistence. Built with Astro, TypeScript, Tailwind CSS, GSAP, and Three.js. Deployed on Netlify.
